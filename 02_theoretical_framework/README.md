# Chapter 2: Theoretical Framework

This chapter establishes the theoretical foundation for integrating evolutionary psychology with Jungian depth psychology.

## Sections

1. **Evolutionary Psychology Foundation** - Mate selection, parental investment, sexual strategies
2. **Jungian Depth Psychology** - Archetypes, collective unconscious, anima/animus projection

Jungian archetypes represent evolutionary psychological structures—inherited patterns that shape mate selection and relationship dynamics in predictable ways.
